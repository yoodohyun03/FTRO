# Survivor Item System - 생존자 아이템 시스템

## 아이템 습득 방법
- 맵 곳곳의 **터미널을 해제**하면 랜덤으로 아이템 1개 지급
- 등급에 따라 드롭 확률 차등 적용

---

## 아이템 등급 및 목록

### [일반] Common — 자주 드롭

| 아이템 | 효과 | 지속 시간 |
|---|---|---|
| **스프린트 부스터** | 이동속도 2배 | 5초 |
| **연막탄** | 반경 5m 시야 차단 | 3초 |
| **마커 교란기** | 술래 HUD에 가짜 플레이어 위치 2~3개 표시 | 5초 |

### [희귀] Rare — 드물게 드롭

| 아이템 | 효과 | 지속 시간 |
|---|---|---|
| **EMP** | 술래 이동속도 감소 + 화면 노이즈 | 3초 |
| **해킹 툴** | 다음 터미널 해제 시간 50% 단축 | 1회 |
| **디코이** | 현재 위치에 가짜 플레이어 잔상 생성, 본인은 반대 방향으로 이동 | 잔상 5초 |

---

## 핵심 설계 원칙
- 아이템은 **터미널 해제 리스크에 대한 보상**
- 술래에게 직접적인 대미지 없음 — 어디까지나 **생존과 위장** 중심
- 희귀 아이템일수록 게임 흐름에 더 큰 영향을 줌

---

## 구현 계획

### 관련 파일
- `ItemSystem.cs` (New): 아이템 수집, 사용, 네트워크 동기화
- `ItemData.cs` (New): ScriptableObject 기반 아이템 정의 (이름, 등급, 효과, 쿨다운)
- `PlayerMove.cs`: 아이템 사용 입력 처리 (E키 등)
- `TerminalController.cs` (New 또는 기존): 터미널 해제 시 아이템 랜덤 지급 로직
- `SeekerHUD.cs`: 마커 교란기 적용 시 가짜 마커 렌더링

### 구현 단계

#### 1단계 — 터미널 → 아이템 지급
- 터미널 해제 완료 시 등급 가중치 기반 랜덤 아이템 선택
- `PhotonNetwork.RPC`로 해당 플레이어에게만 지급 처리

#### 2단계 — 일반 아이템 구현
- **스프린트 부스터**: `PlayerMove.cs`의 `moveSpeed` 일시 증가 + 타이머 코루틴
- **연막탄**: 파티클 이펙트 생성, 술래 카메라 레이캐스트 차단
- **마커 교란기**: 술래 클라이언트 HUD에 가짜 위치 데이터 RPC 전송

#### 3단계 — 희귀 아이템 구현
- **EMP**: 술래 `moveSpeed` 일시 감소 + 화면 포스트프로세싱 노이즈 이펙트
- **해킹 툴**: 다음 터미널 인터랙션 시 해제 시간에 `0.5f` 배수 적용
- **디코이**: 현재 위치에 플레이어 프리팹 복사본 생성 (네트워크 동기화 없는 로컬 오브젝트), 5초 후 파괴

#### 4단계 — UI
- 화면 하단에 보유 아이템 슬롯 표시 (아이콘 + 등급 색상)
- 사용 시 쿨다운/지속 시간 시각화

## 밸런스 메모
- 술래 아이템(Freeze / Swarm)이 AI 50+ 기준으로 강력하므로 생존자 아이템도 충분히 유효해야 함
- 마커 교란기와 디코이는 술래가 HUD에 의존할수록 강력 → HUD 없이도 플레이 가능하게 설계 필요
- EMP는 PvP 요소 → 사거리/발동 조건 테스트 필요
